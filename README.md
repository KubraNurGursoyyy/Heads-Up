# HeadsUp

HeadsUp is an Android-first app for tracking topics and getting notified when relevant developments appear.

Users can create watches using natural language, follow single topics or intersections between two topics, browse related news, and control when notifications are sent.

## Tech Stack

- React Native + Expo
- NestJS
- PostgreSQL + Prisma
- Gemini 2.5 Flash-Lite
- Google News RSS
- Cloudflare Workers
- Expo Push Notifications

## Setup

```bash
npm install
npm run prisma:generate
